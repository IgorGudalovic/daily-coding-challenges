# Pair Sum to Target

- **Difficulty:** easy
- **Solved:** 2026-08-26

## Problem

Title: Pair Sum to Target
Difficulty: easy
Description: Given an integer array and a target integer, determine whether any two distinct elements in the array sum up to the target. Return true if such a pair exists, otherwise return false.
Constraints: 2 <= length of array <= 100000, -10^9 <= each element <= 10^9, -10^9 <= target <= 10^9
Example: array = 2,7,11,15, target = 9 -> true
